# ⚡ 4-Bit Binary Adder

An interactive web-based **4-Bit Binary Adder** that helps users understand binary addition, logic gates, half adders, full adders, and ripple-carry addition through step-by-step simulation.

🔗 **Live Demo:** https://4-bit-adder.vercel.app/

## ✨ Features

* 🔢 Add two 4-bit binary numbers
* ⚡ Interactive step-by-step simulation
* 🔌 Learn XOR, AND & OR logic gates
* 🧮 Half Adder and Full Adder explanation
* 📊 Half Adder & Full Adder truth tables
* 🔄 4-bit Ripple Carry Adder visualization
* 🚨 Displays the final carry/overflow
* 📱 Clean and responsive interface

## 🧠 How It Works

A 4-bit adder is built using **four Full Adders** connected in sequence.

The carry generated by each bit is passed to the next higher bit:

`A0 + B0 → A1 + B1 → A2 + B2 → A3 + B3`

The final carry **C₄** represents the overflow.

### Full Adder

**Sum:**
`S = A ⊕ B ⊕ Cᵢₙ`

**Carry:**
`Cₒᵤₜ = (A · B) + (Cᵢₙ · (A ⊕ B))`
